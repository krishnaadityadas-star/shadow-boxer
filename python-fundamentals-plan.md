# Python Fundamentals Learning Plan

Learn only what the team needs, in this order:

1. Running Python and reading error messages.
2. Variables, numbers, strings and booleans.
3. Operators and conditional statements.
4. `for` and `while` loops.
5. Functions, parameters and return values.
6. Lists, tuples and dictionaries.
7. Imports, modules and installing packages.
8. Basic classes and objects.
9. Reading documentation and debugging.

## Practice approach
For each topic:
- Explain the idea in plain language.
- Run a tiny example.
- Change the example and predict the result.
- Apply it to a small Shadow-Boxer task.

Do not move on until the team can explain and modify the example.
